Kflower 平台“我的应用”模块开发详细设计技术方案
1. 概述与目标
1.1 背景
Kflower 平台目前已具备表单模板设计、数据管理、工作流审批、知识库 RAG、AI 对话等核心能力。用户能够独立创建表单模板，但模板之间彼此孤立，无法组合成一个完整的业务系统（如进销存、CRM 等）。同时，用户需要一种可视化的方式来组织多个表单，配置菜单、定义表单间的数据关系，并能够添加自定义业务逻辑（Python 插件）。

1.2 目标
开发 “我的应用” 模块，允许用户：

创建一个应用（Application），作为业务系统的顶层容器。

将多个已发布的表单模板添加到应用中，配置导航菜单（支持多级菜单）。

定义表单之间的关联关系（外键、子表、聚合计算）。

为应用配置 Python 插件，在数据保存/删除等事件中执行自定义逻辑（如库存扣减、总额计算）。

一键发布应用，生成独立的 Web 应用（左侧菜单 + 动态页面），用户可通过 URL 访问。

利用 AI 辅助设计应用结构（根据自然语言描述自动创建模板、关系、插件）。

1.3 与现有模块的关系
模板设计：提供表单定义。应用中的每个菜单项对应一个已发布的模板。

数据管理：复用现有动态表 CRUD 能力，但需要增加跨表查询和关系处理。

AI 智能体：复用 /api/v1/agent/chat 和 /api/v1/ai/chat 接口，通过专门的系统提示词生成应用配置。

本地 AI 服务：插件代码生成可调用 /api/v1/local-ai/text/... 辅助编写。

权限管理：应用可独立设置访问权限（私有/共享/指定用户）。

4.5.2 通用列表页组件 FormListPage.vue
根据 templateId 调用 /api/v1/templates/{templateId}/data?include_relations=true 获取数据。

动态渲染表格列：根据模板字段定义生成，对于 relation 类型字段，显示关联对象的显示值，并支持点击跳转到关联表单的列表/详情页。

4.5.3 通用表单页组件 FormEditPage.vue
支持新增和编辑两种模式。

根据模板字段定义动态渲染表单控件：

普通字段：同现有 FormFill.vue。

relation 字段：渲染为 <el-select remote>，数据从 /api/v1/templates/{target_template_id}/data 获取，支持远程搜索。

5. 表单间关系实现细节
5.1 relation 字段存储与查询
存储：在动态表中，该字段直接存储目标表记录的 ID（整数）。

列表页查询：后端 include_relations=true 时，动态 LEFT JOIN 获取显示值。

表单页编辑：前端通过远程搜索选择目标记录，选中后存储其 ID。

5.2 subform 字段处理
存储：主表记录不存储子表数据。子表独立存储在子模板的动态表中，通过 parent_id 字段关联。

前端提交：主表数据中 items 字段是一个数组，每个元素对应子表的一条记录（不含 id，但包含 parent_id 占位）。

后端处理：

先插入主表记录，获取 parent_id。
遍历子表数组，为每个元素添加 parent_id，批量插入子表。
更新主表时，需要先删除旧的子表记录（DELETE FROM sub_table WHERE parent_id = :parent_id），再重新插入新数组。
查询：获取主表详情时，需额外查询子表数据并组装到返回 JSON 中。

5.3 跨表单数据统计（聚合计算）
可选方案一：实时计算（如订单总额 = SUM(子表金额)）。在列表页或详情页前端调用子表统计 API 实时计算。

可选方案二：存储计算。通过插件在子表保存/删除时更新主表汇总字段（如 total_amount）。推荐此方案，查询性能好。

"""

from sqlalchemy import Column, Integer, String, Boolean, DateTime, Text, JSON, ForeignKey
from sqlalchemy.orm import relationship
from sqlalchemy.sql import func

from app.core.database import Base


class Application(Base):
    """应用表"""
    __tablename__ = "applications"

    id = Column(Integer, primary_key=True, index=True)
    name = Column(String(200), nullable=False)
    code = Column(String(100), unique=True, nullable=False)
    description = Column(Text, nullable=True)
    icon = Column(String(100), nullable=True)
    theme = Column(String(50), default="light")
    config = Column(JSON, default=dict)
    is_published = Column(Boolean, default=False)
    is_public = Column(Boolean, default=False)
    created_by = Column(Integer, ForeignKey("users.id"), nullable=False)
    organization_id = Column(Integer, ForeignKey("organizations.id"), nullable=True)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())

    # 关系
    menus = relationship("AppMenu", back_populates="app", cascade="all, delete-orphan")
    relations = relationship("FormRelation", back_populates="app", cascade="all, delete-orphan")
    plugins = relationship("AppPlugin", back_populates="app", cascade="all, delete-orphan")
    creator = relationship("User", foreign_keys=[created_by])


class AppMenu(Base):
    """应用菜单"""
    __tablename__ = "app_menus"

    id = Column(Integer, primary_key=True, index=True)
    app_id = Column(Integer, ForeignKey("applications.id"), nullable=False)
    parent_id = Column(Integer, ForeignKey("app_menus.id"), nullable=True)
    template_id = Column(Integer, ForeignKey("templates.id"), nullable=False)
    menu_label = Column(String(100), nullable=False)
    menu_icon = Column(String(100), nullable=True)
    menu_order = Column(Integer, default=0)
    is_visible = Column(Boolean, default=True)
    list_page_config = Column(JSON, default=dict)
    form_page_config = Column(JSON, default=dict)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())

    # 关系
    app = relationship("Application", back_populates="menus")
    parent = relationship("AppMenu", remote_side=[id], backref="children")
    template = relationship("Template")


class FormRelation(Base):
    """表单关系"""
    __tablename__ = "form_relations"

    id = Column(Integer, primary_key=True, index=True)
    app_id = Column(Integer, ForeignKey("applications.id"), nullable=False)
    from_template_id = Column(Integer, ForeignKey("templates.id"), nullable=False)
    from_field_name = Column(String(100), nullable=False)
    to_template_id = Column(Integer, ForeignKey("templates.id"), nullable=False)
    relation_type = Column(String(20), nullable=False)  # belongs_to, has_many, many_to_many
    display_field = Column(String(100), nullable=True)
    on_delete = Column(String(20), default="set_null")
    reverse_name = Column(String(100), nullable=True)
    created_at = Column(DateTime, server_default=func.now())

    # 关系
    app = relationship("Application", back_populates="relations")
    from_template = relationship("Template", foreign_keys=[from_template_id])
    to_template = relationship("Template", foreign_keys=[to_template_id])


class AppPlugin(Base):
    """应用插件"""
    __tablename__ = "app_plugins"

    id = Column(Integer, primary_key=True, index=True)
    app_id = Column(Integer, ForeignKey("applications.id"), nullable=False)
    name = Column(String(100), nullable=False)
    trigger_event = Column(String(50), nullable=False)  # before_save, after_save, before_delete, after_delete, on_load
    target_template_id = Column(Integer, ForeignKey("templates.id"), nullable=True)
    script_code = Column(Text, nullable=False)
    is_enabled = Column(Boolean, default=True)
    created_at = Column(DateTime, server_default=func.now())
    updated_at = Column(DateTime, server_default=func.now(), onupdate=func.now())

    # 关系
    app = relationship("Application", back_populates="plugins")
    target_template = relationship("Template")

"""
插件安全执行器 - 基于 RestrictedPython
"""
import sys
import logging
from typing import Dict, Any, Optional
from sqlalchemy.ext.asyncio import AsyncSession

logger = logging.getLogger(__name__)

try:
    from RestrictedPython import compile_restricted
    from RestrictedPython import safe_globals
    RESTRICTED_AVAILABLE = True
except ImportError:
    RESTRICTED_AVAILABLE = False
    logger.warning("RestrictedPython 未安装，插件执行将使用 eval（不安全，仅用于开发）")


class PluginContext:
    """插件执行上下文"""
    def __init__(self, data: Dict[str, Any], db: AsyncSession, api_client=None):
        self.data = data
        self.db = db
        self.api = api_client  # 预留平台 API 客户端
        self.logger = logger


class PluginExecutor:
    """插件执行器"""

    @staticmethod
    async def execute(script_code: str, context: PluginContext, timeout_seconds: int = 5) -> Dict[str, Any]:
        """
        执行插件脚本
        :return: {"success": bool, "output": any, "error": str}
        """
        if not script_code or not script_code.strip():
            return {"success": False, "error": "插件代码为空"}

        # 准备安全环境
        safe_builtins = {
            'abs': abs,
            'all': all,
            'any': any,
            'bool': bool,
            'dict': dict,
            'enumerate': enumerate,
            'float': float,
            'int': int,
            'len': len,
            'list': list,
            'max': max,
            'min': min,
            'pow': pow,
            'range': range,
            'round': round,
            'set': set,
            'sorted': sorted,
            'str': str,
            'sum': sum,
            'tuple': tuple,
            'zip': zip,
            'print': print,
        }

        if RESTRICTED_AVAILABLE:
            # 使用 RestrictedPython 编译
            byte_code = compile_restricted(script_code, filename='<plugin>', mode='exec')
            if byte_code.errors:
                return {"success": False, "error": f"编译错误: {byte_code.errors}"}

            # 执行环境
            restricted_globals = safe_globals.copy()
            restricted_globals['__builtins__'] = safe_builtins
            restricted_globals['context'] = context
            restricted_globals['__name__'] = '__plugin__'

            try:
                exec(byte_code.code, restricted_globals)
                # 查找函数（约定函数名为 trigger_event 名称，如 after_save）
                func_name = None
                for name in ['after_save', 'before_save', 'after_delete', 'before_delete', 'on_load']:
                    if name in restricted_globals:
                        func_name = name
                        break
                if func_name:
                    result = restricted_globals[func_name](context)
                    return {"success": True, "output": result}
                else:
                    # 如果找不到特定函数，执行整个脚本（可能直接写了语句）
                    return {"success": True, "output": None}
            except Exception as e:
                logger.exception("插件执行异常")
                return {"success": False, "error": str(e)}
        else:
            # 降级方案：使用 eval（不安全，仅开发环境）
            try:
                # 创建独立命名空间
                namespace = {'context': context, '__builtins__': safe_builtins}
                exec(script_code, namespace)
                # 查找函数
                func = None
                for name in ['after_save', 'before_save', 'after_delete', 'before_delete', 'on_load']:
                    if name in namespace:
                        func = namespace[name]
                        break
                if func:
                    result = func(context)
                    return {"success": True, "output": result}
                return {"success": True, "output": None}
            except Exception as e:
                return {"success": False, "error": str(e)}

"""

from sqlalchemy.ext.asyncio import AsyncSession
from sqlalchemy import select, update, delete, func
from typing import List, Optional, Dict, Any
import uuid

from app.modules.my_apps.models import Application, AppMenu, FormRelation, AppPlugin
from app.modules.my_apps.schemas import (
    ApplicationCreate, ApplicationUpdate,
    AppMenuCreate, AppMenuUpdate,
    FormRelationCreate, FormRelationUpdate,
    AppPluginCreate, AppPluginUpdate,
    MenuTreeNode
)
from app.models.workflow import Template
from app.models.user import User


class MyAppsService:
    """我的应用服务"""

    # ========== 应用 CRUD ==========
    @staticmethod
    async def create_app(db: AsyncSession, user: User, data: ApplicationCreate) -> Application:
        code = f"app_{uuid.uuid4().hex[:8]}"
        app = Application(
            name=data.name,
            code=code,
            description=data.description,
            icon=data.icon,
            theme=data.theme,
            config=data.config or {},
            created_by=user.id,
            organization_id=user.organization_id,
        )
        db.add(app)
        await db.commit()
        await db.refresh(app)
        return app

    @staticmethod
    async def get_apps(db: AsyncSession, user: User) -> List[Application]:
        query = select(Application).where(Application.created_by == user.id)
        if user.organization_id:
            query = query.where(Application.organization_id == user.organization_id)
        result = await db.execute(query.order_by(Application.created_at.desc()))
        return result.scalars().all()

    @staticmethod
    async def get_app(db: AsyncSession, app_id: int, user: User) -> Optional[Application]:
        query = select(Application).where(Application.id == app_id, Application.created_by == user.id)
        result = await db.execute(query)
        return result.scalar_one_or_none()

    @staticmethod
    async def update_app(db: AsyncSession, app: Application, data: ApplicationUpdate) -> Application:
        for key, value in data.model_dump(exclude_unset=True).items():
            setattr(app, key, value)
        await db.commit()
        await db.refresh(app)
        return app

    @staticmethod
    async def delete_app(db: AsyncSession, app: Application):
        await db.delete(app)
        await db.commit()

    @staticmethod
    async def publish_app(db: AsyncSession, app: Application) -> Application:
        app.is_published = True
        await db.commit()
        await db.refresh(app)
        return app

    # ========== 菜单管理 ==========
    @staticmethod
    async def add_menu(db: AsyncSession, app_id: int, data: AppMenuCreate) -> AppMenu:
        menu = AppMenu(
            app_id=app_id,
            parent_id=data.parent_id,
            template_id=data.template_id,
            menu_label=data.menu_label,
            menu_icon=data.menu_icon,
            menu_order=data.menu_order,
            is_visible=data.is_visible,
            list_page_config=data.list_page_config,
            form_page_config=data.form_page_config,
        )
        db.add(menu)
        await db.commit()
        await db.refresh(menu)
        return menu

    @staticmethod
    async def update_menu(db: AsyncSession, menu: AppMenu, data: AppMenuUpdate) -> AppMenu:
        for key, value in data.model_dump(exclude_unset=True).items():
            setattr(menu, key, value)
        await db.commit()
        await db.refresh(menu)
        return menu

    @staticmethod
    async def delete_menu(db: AsyncSession, menu: AppMenu):
        await db.delete(menu)
        await db.commit()

    @staticmethod
    async def get_menu_tree(db: AsyncSession, app_id: int) -> List[MenuTreeNode]:
        result = await db.execute(
            select(AppMenu).where(AppMenu.app_id == app_id).order_by(AppMenu.menu_order)
        )
        menus = result.scalars().all()
        # 构建树
        menu_map = {m.id: MenuTreeNode(
            id=m.id,
            label=m.menu_label,
            icon=m.menu_icon,
            path=f"/app/{app_id}/form/{m.template_id}",
            template_id=m.template_id,
            children=[]
        ) for m in menus}
        roots = []
        for m in menus:
            node = menu_map[m.id]
            if m.parent_id and m.parent_id in menu_map:
                menu_map[m.parent_id].children.append(node)
            else:
                roots.append(node)
        return roots

    # ========== 关系管理 ==========
    @staticmethod
    async def add_relation(db: AsyncSession, app_id: int, data: FormRelationCreate) -> FormRelation:
        relation = FormRelation(
            app_id=app_id,
            from_template_id=data.from_template_id,
            from_field_name=data.from_field_name,
            to_template_id=data.to_template_id,
            relation_type=data.relation_type,
            display_field=data.display_field,
            on_delete=data.on_delete,
            reverse_name=data.reverse_name,
        )
        db.add(relation)
        await db.commit()
        await db.refresh(relation)
        return relation

    @staticmethod
    async def get_relations(db: AsyncSession, app_id: int) -> List[FormRelation]:
        result = await db.execute(
            select(FormRelation).where(FormRelation.app_id == app_id)
        )
        return result.scalars().all()

    @staticmethod
    async def delete_relation(db: AsyncSession, relation: FormRelation):
        await db.delete(relation)
        await db.commit()

    # ========== 插件管理 ==========
    @staticmethod
    async def add_plugin(db: AsyncSession, app_id: int, data: AppPluginCreate) -> AppPlugin:
        plugin = AppPlugin(
            app_id=app_id,
            name=data.name,
            trigger_event=data.trigger_event,
            target_template_id=data.target_template_id,
            script_code=data.script_code,
            is_enabled=data.is_enabled,
        )
        db.add(plugin)
        await db.commit()
        await db.refresh(plugin)
        return plugin

    @staticmethod
    async def get_plugins(db: AsyncSession, app_id: int) -> List[AppPlugin]:
        result = await db.execute(
            select(AppPlugin).where(AppPlugin.app_id == app_id)
        )
        return result.scalars().all()

    @staticmethod
    async def update_plugin(db: AsyncSession, plugin: AppPlugin, data: AppPluginUpdate) -> AppPlugin:
        for key, value in data.model_dump(exclude_unset=True).items():
            setattr(plugin, key, value)
        await db.commit()
        await db.refresh(plugin)
        return plugin

    @staticmethod
    async def delete_plugin(db: AsyncSession, plugin: AppPlugin):
        await db.delete(plugin)
        await db.commit()

    # ========== 辅助方法：获取应用完整详情 ==========
    @staticmethod
    async def get_app_detail(db: AsyncSession, app_id: int, user: User) -> Optional[Dict]:
        app = await MyAppsService.get_app(db, app_id, user)
        if not app:
            return None
        # 获取菜单树
        menu_tree = await MyAppsService.get_menu_tree(db, app_id)
        # 获取关系
        relations = await MyAppsService.get_relations(db, app_id)
        # 获取插件
        plugins = await MyAppsService.get_plugins(db, app_id)

        return {
            **app.__dict__,
            "menus": menu_tree,
            "relations": [r.__dict__ for r in relations],
            "plugins": [p.__dict__ for p in plugins],
        }

"""

from fastapi import APIRouter, Depends, HTTPException, Query
from sqlalchemy.ext.asyncio import AsyncSession
from typing import List, Optional

from app.core.database import get_db
from app.core.security import get_current_user
from app.models.user import User
from app.modules.my_apps.service import my_apps_service
from app.modules.my_apps.schemas import (
    ApplicationCreate, ApplicationUpdate, ApplicationResponse, AppDetailResponse,
    AppMenuCreate, AppMenuUpdate, AppMenuResponse,
    FormRelationCreate, FormRelationUpdate, FormRelationResponse,
    AppPluginCreate, AppPluginUpdate, AppPluginResponse,
    MenuTreeNode
)
from app.modules.my_apps.plugin_executor import plugin_executor, PluginContext
from app.schemas.schemas import BaseResponse

router = APIRouter(prefix="/apps", tags=["我的应用"])


# ========== 应用管理 ==========
@router.post("/", response_model=ApplicationResponse)
async def create_app(
    data: ApplicationCreate,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    app = await my_apps_service.create_app(db, current_user, data)
    return app


@router.get("/", response_model=List[ApplicationResponse])
async def list_apps(
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    apps = await my_apps_service.get_apps(db, current_user)
    return apps


@router.get("/{app_id}", response_model=AppDetailResponse)
async def get_app(
    app_id: int,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    detail = await my_apps_service.get_app_detail(db, app_id, current_user)
    if not detail:
        raise HTTPException(status_code=404, detail="应用不存在")
    return detail


@router.put("/{app_id}", response_model=ApplicationResponse)
async def update_app(
    app_id: int,
    data: ApplicationUpdate,
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    app = await my_apps_service.get_app(db, app_id, current_user)
    if not app:
        raise HTTPException(status_code=404, detail="应用不存在")
    app = await my_apps_service.update_app(db, app, data)
    return app


@router.delete("/{app_id}")
async def delete_app(
    app_id: int,
    db: AsyncSession = Depends(get_db),

<script setup>
import { ref, onMounted } from 'vue'
import { useRouter } from 'vue-router'
import { ElMessage, ElMessageBox } from 'element-plus'
import { Plus, FolderOpened } from '@element-plus/icons-vue'
import { myAppsAPI } from '@/api/myApps'

const router = useRouter()
const loading = ref(false)
const apps = ref([])
const createDialogVisible = ref(false)
const creating = ref(false)
const createForm = ref({ name: '', description: '', icon: 'FolderOpened' })

function formatDate(dateStr) {
  if (!dateStr) return '-'
  return new Date(dateStr).toLocaleDateString()
}

async function loadApps() {
  loading.value = true
  try {
    const res = await myAppsAPI.list()
    apps.value = res.data || res
  } catch (e) {
    ElMessage.error('加载应用列表失败')
  } finally {
    loading.value = false
  }
}

function openCreateDialog() {
  createForm.value = { name: '', description: '', icon: 'FolderOpened' }
  createDialogVisible.value = true
}

async function handleCreate() {
  if (!createForm.value.name.trim()) {
    ElMessage.warning('请输入应用名称')
    return
  }
  creating.value = true
  try {
    const res = await myAppsAPI.create(createForm.value)
    ElMessage.success('应用创建成功')
    createDialogVisible.value = false
    await loadApps()
    // 自动进入设计器
    openDesigner(res.data.id)
  } catch (e) {
    ElMessage.error(e.message || '创建失败')
  } finally {
    creating.value = false
  }
}

function openDesigner(appId) {
  router.push(`/my-apps/designer/${appId}`)
}

async function publishApp(app) {
  try {
    await ElMessageBox.confirm(`确定发布应用“${app.name}”吗？发布后用户可通过链接访问。`, '提示')
    await myAppsAPI.publish(app.id)

  } catch (e) {}
}

async function deleteApp(app) {
  try {

    await myAppsAPI.delete(app.id)
    ElMessage.success('删除成功')
    await loadApps()
  } catch (e) {}
}

onMounted(() => {
  loadApps()
})

// 在 router/index.js 中
import { myAppsAPI } from '@/api/myApps'

// 动态添加应用路由
async function addAppRoutes() {
  const res = await myAppsAPI.list()
  const apps = res.data || res
  for (const app of apps) {
    if (app.is_published) {
      router.addRoute({
        path: `/app/${app.id}`,
        name: `app_${app.id}`,
        component: () => import('@/views/my-apps/AppLayout.vue'),
        meta: { appId: app.id, requiresAuth: true }
      })
    }
  }
}

6. 通用列表页 (FormListPage.vue) 和 通用表单页 (FormEditPage.vue)
这两个组件需要根据模板定义动态渲染表格和表单，并支持关系字段。由于代码量巨大，这里给出核心实现思路，实际开发时可参考现有 FormData.vue 和 FormFill.vue 进行扩展。

FormListPage.vue 核心要点：

接收 props: templateId, appId

调用 GET /api/v1/templates/${templateId}/data?include_relations=true 获取数据（已包含关联对象显示值）

动态生成表格列，对于 relation 类型字段，渲染为可点击链接，跳转到关联表单的列表页（带过滤参数）

操作列包含“新增”、“编辑”、“删除”

新增按钮跳转到 /app/${appId}/form/${templateId}/edit

FormEditPage.vue 核心要点：

接收 props: templateId, appId, id (可选)

根据模板字段定义动态生成表单

relation 字段使用 <el-select remote> 从目标模板的 /data 接口加载数据

subform 字段使用 <el-table> 实现行内编辑，支持增删行

提交时调用 /api/v1/templates/${templateId}/submit，子表数据作为数组包含在 data 中

以上是“我的应用”模块的完整实现代码。由于代码量较大，部分组件（如菜单树编辑器、关系图配置、插件编辑器）未给出完整代码，但已提供核心 API 和结构，可根据实际需求进一步开发。该模块独立于主程序，通过 app/modules/my_apps 目录组织，便于维护和升级。

    const fields = []
    for (const mod of tpl.modules) {
      if (mod.fields) {
        fields.push(...mod.fields)
      }
    }
    fromFields.value = fields
  } else {
    fromFields.value = []
  }

<script setup>
import { ref, reactive, onMounted, computed } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { ElMessage } from 'element-plus'
import { Plus } from '@element-plus/icons-vue'
import { templateAPI } from '@/common/api'
import { myAppsAPI } from '@/api/myApps'

const route = useRoute()
const router = useRouter()
const appId = computed(() => route.params.appId)
const templateId = computed(() => route.params.templateId)
const recordId = computed(() => route.params.id)

const templateName = ref('')
const fields = ref([])
const subformFields = ref({})
const formData = reactive({})
const rules = ref({})
const loading = ref(false)
const submitting = ref(false)
const relationLoading = ref(false)
const relationOptions = ref({})

async function loadTemplate() {
  const res = await templateAPI.get(templateId.value)
  const tpl = res.data || res
  templateName.value = tpl.name
  // 解析字段
  const allFields = []
  if (tpl.modules) {
    for (const mod of tpl.modules) {
      for (const field of mod.fields) {
        allFields.push(field)
        if (field.type === 'subform') {
          // 加载子表单模板的字段定义
          const subRes = await templateAPI.get(field.subform_config.template_id)
          const subTpl = subRes.data || subRes
          const subFields = []
          if (subTpl.modules) {
            for (const subMod of subTpl.modules) {
              subFields.push(...subMod.fields)
            }
          }
          subformFields.value[field.subform_config.template_id] = subFields
        }
      }
    }
  }
  fields.value = allFields

  // 构建验证规则
  for (const field of allFields) {
    if (field.required) {
      rules.value[field.name] = [{ required: true, message: `请填写${field.label}`, trigger: 'change' }]
    }
  }

  // 加载关系配置
  const relationsRes = await myAppsAPI.listRelations(appId.value)
  const relations = relationsRes.data || []
  for (const field of allFields) {
    const relation = relations.find(r => r.from_field_name === field.name && r.relation_type === 'belongs_to')
    if (relation) {
      field.type = 'relation'
      field.relation = relation
      relationOptions.value[field.name] = []
    }
  }
}

async function loadData() {
  if (!recordId.value) {
    // 新增模式：初始化默认值
    for (const field of fields.value) {
      if (field.type === 'subform') {
        formData[field.name] = []
      } else if (field.type === 'switch') {
        formData[field.name] = false
      } else if (field.type === 'checkbox') {
        formData[field.name] = []
      } else {
        formData[field.name] = ''
      }
    }
    return
  }

  loading.value = true
  try {
    const res = await templateAPI.getDataDetail(templateId.value, recordId.value)
    const data = res.data || res
    for (const field of fields.value) {
      if (field.type === 'subform') {
        // 加载子表数据
        const subRes = await templateAPI.getData(field.subform_config.template_id, {
          parent_id: recordId.value
        })
        formData[field.name] = subRes.data || []
      } else {
        formData[field.name] = data[field.name]
      }
    }
  } catch (e) {
    ElMessage.error('加载数据失败')
  } finally {
    loading.value = false
  }
}

async function searchRelation(field, query) {
  if (!query) return
  relationLoading.value = true
  try {
    const targetId = field.relation.to_template_id
    const res = await templateAPI.getData(targetId, { search: query, limit: 20 })
    relationOptions.value[field.name] = Array.isArray(res) ? res : (res.data || [])
  } catch (e) {
    console.error(e)
  } finally {
    relationLoading.value = false
  }
}

function addSubRow(field) {
  const newRow = {}
  const subFields = subformFields.value[field.subform_config.template_id] || []
  for (const subField of subFields) {
    newRow[subField.name] = ''
  }
  formData[field.name].push(newRow)
}

function removeSubRow(field, index) {
  formData[field.name].splice(index, 1)
}

async function submitForm() {
  submitting.value = true
  try {
    const submitData = { ...formData }
    await templateAPI.submitData(templateId.value, { data: submitData })
    ElMessage.success('保存成功')
    goBack()
  } catch (e) {
    ElMessage.error(e.message || '保存失败')
  } finally {
    submitting.value = false
  }
}

  router.push(`/app/${appId.value}/form/${templateId.value}`)
}

async function loadTemplate() {
  try {
    const res = await templateAPI.get(templateId.value)
    templateName.value = res.name
    // 提取字段（排除布局元素）
    const fields = []
    if (res.modules) {
      for (const mod of res.modules) {
        for (const f of mod.fields) {
          if (!['divider', 'title', 'description'].includes(f.type)) {
            fields.push(f)

        }

      skip,

  } finally {

  }
}

<script setup>
import { ref, reactive, computed, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { ElMessage } from 'element-plus'
import { Plus, Delete } from '@element-plus/icons-vue'
import { templateAPI } from '@/common/api'

const route = useRoute()
const router = useRouter()
const templateId = computed(() => route.params.templateId)
const recordId = computed(() => route.params.id)

const templateName = ref('')
const displayFields = ref([])
const formData = reactive({})
const formRef = ref(null)
const submitting = ref(false)
const loading = ref(false)

// 关联字段相关
const relationOptions = ref({})
const relationLoading = ref({})

// 子表单相关
const subformFields = ref({})

const formRules = computed(() => {
  const rules = {}
  for (const field of displayFields.value) {
    if (field.required) {
      rules[field.name] = [{ required: true, message: `请填写${field.label}`, trigger: 'change' }]
    }
  }
  return rules
})

async function loadTemplate() {
  const res = await templateAPI.get(templateId.value)
  templateName.value = res.name
  const fields = []
  if (res.modules) {
    for (const mod of res.modules) {
      for (const f of mod.fields) {
        if (!['divider', 'title', 'description'].includes(f.type)) {
          fields.push(f)
          // 初始化表单默认值
          if (f.type === 'checkbox' || (f.type === 'select' && f.multiple)) {
            formData[f.name] = []
          } else if (f.type === 'subform') {
            formData[f.name] = []
            subformFields.value[f.name] = f.subform_config?.fields || []
          } else {
            formData[f.name] = f.defaultValue || ''
          }
          // 初始化关联字段选项
          if (f.type === 'relation') {
            relationOptions.value[f.name] = []
          }
        }
      }
    }
  }
  displayFields.value = fields
}

async function loadData() {
  if (!recordId.value) return
  loading.value = true
  try {
    const res = await templateAPI.getDataDetail(templateId.value, recordId.value)
    const data = res.config?.data || res
    for (const field of displayFields.value) {
      if (data[field.name] !== undefined) {
        formData[field.name] = data[field.name]
      }
    }
  } catch (e) {
    ElMessage.error('加载数据失败')
  } finally {
    loading.value = false
  }
}

async function searchRelation(field, query) {
  const targetId = field.relation_config?.target_template_id
  if (!targetId) return
  relationLoading.value[field.name] = true
  try {
    const res = await templateAPI.getData(targetId, { search: query, limit: 20 })
    relationOptions.value[field.name] = Array.isArray(res) ? res : (res.items || [])
  } catch (e) {
    console.error(e)
  } finally {
    relationLoading.value[field.name] = false
  }
}

function addSubformRow(field) {
  const newRow = {}
  const fields = subformFields.value[field.name] || []
  for (const f of fields) {
    newRow[f.name] = f.defaultValue || ''
  }
  if (!formData[field.name]) {
    formData[field.name] = []
  }
  formData[field.name].push(newRow)
}

function removeSubformRow(field, index) {
  formData[field.name].splice(index, 1)
}

async function submitForm() {
  const valid = await formRef.value?.validate().catch(() => false)
  if (!valid) return

  submitting.value = true
  try {
    const submitData = { ...formData }
    if (recordId.value) {
      await templateAPI.updateData(templateId.value, recordId.value, { data: submitData })
      ElMessage.success('更新成功')
    } else {
      await templateAPI.submitData(templateId.value, { data: submitData })
      ElMessage.success('提交成功')
    }
    router.back()
  } catch (e) {
    ElMessage.error(e.message || '提交失败')
  } finally {
    submitting.value = false
  }
}

onMounted(() => {
  loadTemplate()
  loadData()
})

<script setup>
import { ref, computed, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { ElMessage, ElMessageBox } from 'element-plus'
import { Plus, Search } from '@element-plus/icons-vue'
import { templateAPI } from '@/common/api'
import { myAppsAPI } from '@/api/myApps'

const route = useRoute()
const router = useRouter()
const appId = computed(() => route.params.appId)
const templateId = computed(() => route.params.templateId)

const templateName = ref('')
const loading = ref(false)
const tableData = ref([])
const total = ref(0)
const currentPage = ref(1)
const pageSize = ref(20)
const searchKeyword = ref('')
const fields = ref([])
const relations = ref([])  // 应用内关系配置

async function loadTemplate() {
  try {
    const res = await templateAPI.get(templateId.value)
    templateName.value = res.name
    // 提取字段（排除布局元素）
    const allFields = []
    if (res.modules) {
      for (const mod of res.modules) {
        for (const f of mod.fields) {
          if (!['divider', 'title', 'description'].includes(f.type)) {
            allFields.push(f)
          }
        }
      }
    }
    fields.value = allFields
  } catch (e) {
    ElMessage.error('加载模板失败')
  }
}

async function loadRelations() {
  try {
    const res = await myAppsAPI.listRelations(appId.value)
    relations.value = res.data || []
  } catch (e) {
    // 忽略
  }
}

const displayColumns = computed(() => {
  const cols = []
  for (const field of fields.value) {
    // 查找关系配置
    const relation = relations.value.find(r => 
      r.from_template_id === templateId.value && r.from_field_name === field.name
    )
    if (relation) {
      cols.push({
        name: field.name,
        prop: `${field.name}_display`,  // 后端返回的关联显示值字段名
        label: field.label,
        type: 'relation',
        isRelation: true,
        relationFieldId: field.name,
        relationTargetTemplateId: relation.to_template_id
      })
    } else {
      cols.push({
        name: field.name,
        prop: field.name,
        label: field.label,
        type: field.type,
        width: field.type === 'textarea' ? 200 : 120
      })
    }
  }
  return cols
})

async function loadData() {
  loading.value = true
  try {
    const skip = (currentPage.value - 1) * pageSize.value
    const res = await templateAPI.getData(templateId.value, {
      skip,
      limit: pageSize.value,
      search: searchKeyword.value || undefined,
      include_relations: true  // 需要后端支持
    })
    if (Array.isArray(res)) {
      tableData.value = res
      total.value = res.length
    } else {
      tableData.value = res.data || []
      total.value = res.total || 0
    }
  } catch (e) {
    ElMessage.error('加载数据失败')
  } finally {
    loading.value = false
  }
}

            <!-- 多行文本 -->
            <el-input
              v-else-if="field.type === 'textarea'"
              v-model="formData[field.name]"
              type="textarea"
              :rows="4"
              :placeholder="field.placeholder"
            />
            <!-- 数字 -->
            <el-input-number

              v-model="formData[field.name]"
              style="width:100%"
              :min="field.min"
              :max="field.max"

              v-else-if="field.type === 'date'"
              v-model="formData[field.name]"

              style="width:100%"

                      v-if="subField.type === 'text'"
                      v-model="row[subField.name]"

                      v-else-if="subField.type === 'number'"
                      v-model="row[subField.name]"
                      style="width:100%"
                    />

<script setup>
import { ref, reactive, computed, onMounted } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import { ElMessage } from 'element-plus'
import { Plus } from '@element-plus/icons-vue'
import { templateAPI } from '@/common/api'
import { myAppsAPI } from '@/api/myApps'

const route = useRoute()
const router = useRouter()
const appId = computed(() => route.params.appId)
const templateId = computed(() => route.params.templateId)
const recordId = computed(() => route.params.id)

const templateName = ref('')
const loading = ref(false)
const submitting = ref(false)
const fields = ref([])
const formData = reactive({})
const rules = ref({})
const relations = ref([])

// 关联字段相关
const relationOptions = ref({})
const relationLoading = ref({})

// 子表单相关
const subformFields = ref({})  // 子表单的字段定义

async function loadTemplate() {
  loading.value = true
  try {
    const res = await templateAPI.get(templateId.value)
    templateName.value = res.name
    const allFields = []
    if (res.modules) {
      for (const mod of res.modules) {
        for (const f of mod.fields) {
          allFields.push(f)
          // 初始化表单默认值
          if (f.type === 'checkbox' || (f.type === 'select' && f.multiple)) {
            formData[f.name] = []
          } else if (f.type === 'switch') {
            formData[f.name] = false
          } else {
            formData[f.name] = ''
          }
          // 构建验证规则
          if (f.required) {
            rules.value[f.name] = [{ required: true, message: `请填写${f.label}`, trigger: 'blur' }]
          }
          // 子表单字段
          if (f.type === 'subform' && f.subform_config) {
            await loadSubformTemplate(f)
            formData[f.name] = []
          }
        }
      }
    }
    fields.value = allFields
  } catch (e) {
    ElMessage.error('加载模板失败')
  } finally {
    loading.value = false
  }
}

async function loadRelations() {
  try {
    const res = await myAppsAPI.listRelations(appId.value)
    relations.value = res.data || []
  } catch (e) {}
}

async function loadSubformTemplate(field) {
  const subTplId = field.subform_config.template_id
  try {
    const res = await templateAPI.get(subTplId)
    const subFields = []
    if (res.modules) {
      for (const mod of res.modules) {
        for (const f of mod.fields) {
          if (f.type !== 'divider' && f.type !== 'title') {
            subFields.push(f)
          }
        }
      }
    }
    subformFields.value[field.name] = subFields
  } catch (e) {
    console.error('加载子表单模板失败', e)
  }
}

async function loadData() {
  if (!recordId.value) return
  loading.value = true
  try {
    const res = await templateAPI.getDataDetail(templateId.value, recordId.value)
    Object.assign(formData, res.config?.data || {})
    // 加载子表数据
    for (const field of fields.value) {
      if (field.type === 'subform' && field.subform_config) {
        const subRes = await templateAPI.getData(field.subform_config.template_id, {
          parent_id: recordId.value
        })
        formData[field.name] = subRes.data || []
      }
    }
  } catch (e) {
    ElMessage.error('加载数据失败')
  } finally {
    loading.value = false
  }
}

async function searchRelationTarget(field, query) {
  const targetTplId = field.relation_config.target_template_id
  relationLoading.value[field.name] = true
  try {
    const res = await templateAPI.getData(targetTplId, { search: query, limit: 20 })
    relationOptions.value[field.name] = res.data || []
  } catch (e) {
    console.error(e)
  } finally {
    relationLoading.value[field.name] = false
  }
}

function addSubformRow(field) {
  const newRow = {}
  for (const subField of subformFields.value[field.name]) {
    newRow[subField.name] = subField.type === 'number' ? 0 : ''
  }
  if (!formData[field.name]) formData[field.name] = []
  formData[field.name].push(newRow)
}

function removeSubformRow(field, index) {
  formData[field.name].splice(index, 1)
}

async function submitForm() {
  submitting.value = true
  try {
    const dataToSubmit = { ...formData }
    await templateAPI.submitData(templateId.value, { data: dataToSubmit })
    ElMessage.success('保存成功')
    goBack()
  } catch (e) {
    ElMessage.error(e.message || '保存失败')
  } finally {
    submitting.value = false
  }
}

function goBack() {
  router.push(`/app/${appId.value}/form/${templateId.value}`)
}

onMounted(() => {
  loadTemplate()
  loadRelations()
  loadData()
})
</script>

import { myAppsAPI } from '@/api/myApps'

async function addAppRoutes() {
  try {
    const res = await myAppsAPI.list()
    const apps = res.data || res
    for (const app of apps) {
      if (app.is_published) {
        router.addRoute({
          path: `/app/${app.id}`,
          component: () => import('@/views/my-apps/AppLayout.vue'),
          meta: { appId: app.id, requiresAuth: true },
          children: [
            // 动态子路由将在 AppLayout 中根据菜单动态添加
          ]
        })
      }
    }
  } catch (e) {
    console.warn('加载应用路由失败', e)
  }
}

执行以下 SQL 创建新表（或使用 Alembic 迁移）：

sql
-- 应用表
CREATE TABLE IF NOT EXISTS applications (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name VARCHAR(200) NOT NULL,
    code VARCHAR(100) UNIQUE NOT NULL,
    description TEXT,
    icon VARCHAR(100),
    theme VARCHAR(50) DEFAULT 'light',
    config JSON,
    is_published BOOLEAN DEFAULT 0,
    is_public BOOLEAN DEFAULT 0,
    created_by INTEGER NOT NULL,
    organization_id INTEGER,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (created_by) REFERENCES users(id),
    FOREIGN KEY (organization_id) REFERENCES organizations(id)
);

-- 应用菜单表
CREATE TABLE IF NOT EXISTS app_menus (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER NOT NULL,
    parent_id INTEGER,
    template_id INTEGER NOT NULL,
    menu_label VARCHAR(100) NOT NULL,
    menu_icon VARCHAR(100),
    menu_order INTEGER DEFAULT 0,
    is_visible BOOLEAN DEFAULT 1,
    list_page_config JSON,
    form_page_config JSON,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (app_id) REFERENCES applications(id),
    FOREIGN KEY (parent_id) REFERENCES app_menus(id),
    FOREIGN KEY (template_id) REFERENCES templates(id)
);

-- 表单关系表
CREATE TABLE IF NOT EXISTS form_relations (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER NOT NULL,
    from_template_id INTEGER NOT NULL,
    from_field_name VARCHAR(100) NOT NULL,
    to_template_id INTEGER NOT NULL,
    relation_type VARCHAR(20) NOT NULL,
    display_field VARCHAR(100),
    on_delete VARCHAR(20) DEFAULT 'set_null',
    reverse_name VARCHAR(100),
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (app_id) REFERENCES applications(id),
    FOREIGN KEY (from_template_id) REFERENCES templates(id),
    FOREIGN KEY (to_template_id) REFERENCES templates(id)
);

-- 应用插件表
CREATE TABLE IF NOT EXISTS app_plugins (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    app_id INTEGER NOT NULL,
    name VARCHAR(100) NOT NULL,
    trigger_event VARCHAR(50) NOT NULL,
    target_template_id INTEGER,
    script_code TEXT NOT NULL,
    is_enabled BOOLEAN DEFAULT 1,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (app_id) REFERENCES applications(id),
    FOREIGN KEY (target_template_id) REFERENCES templates(id)
);
