## 一、项目概述

### 1.1 平台定位
Kflower 是一款 AI 原生的企业智能管理低代码平台，深度融合 AI 大模型与多智能体系统（MAS）技术，实现从"零代码开发"到"智能体驱动开发"的跨越升级。

### 1.2 技术栈
| 层级 | 技术选型 |
|------|----------|
| 前端 PC 端 | Vue 3.5 + TypeScript + Vite 7 + Element Plus + Pinia |
| 前端移动端 | Vue 3.5 + TypeScript + Vant 4 + Pinia（app目录，自动设备检测） |
| 后端框架 | FastAPI + Python 3.11 + Pydantic V2 |
| ORM | SQLAlchemy 2.0 + Alembic（异步支持） |
| 开发数据库 | SQLite（aiosqlite） |
| 生产数据库 | MySQL 8.0+ / PostgreSQL 16+ |
| 向量数据库 | pgvector / Qdrant |
| AI 大模型 | DeepSeek / 通义千问 / Llama（支持云端API与私有化） |
| 智能体框架 | LangChain + 自研编排引擎 |
| 消息队列 | Redis Streams |

### 1.3 十一大功能模块
1. **模板设计** - AI智能生成引擎
2. **决策分析** - 智能洞察引擎
3. **流程审批** - 智能流程引擎
4. **数据集成** - 智能连接引擎
5. **用户权限** - 智能安全引擎
6. **系统设置** - 智能运维引擎
7. **设计方案** - 行业解决方案
8. **部署维护** - 智能部署
9. **工作台设置** - 个性化配置
10. **工作台** - 智能工作台
11. **移动设置** - 跨端适配

## 五、关键设计决策

### 5.1 AI数字底座贯穿全程
- 所有业务模块均可调用 AI 服务
- AI 能力作为平台核心基础设施
- 支持多模型切换（DeepSeek/通义千问）

### 5.2 智能体引擎架构
```
用户请求 → AI网关 → 意图识别 → 智能体编排器
    ↓
任务规划 → 工具调用 → 执行反馈 → 记忆管理
    ↓
结果聚合 → 响应输出 → 知识沉淀
```

### 5.3 多端自动适配
- 设备检测：User-Agent + 屏幕宽度
- 路由切换：自动跳转 PC/app 目录
- 共享逻辑：common 目录统一封装

### 5.4 数据库策略
- 开发：SQLite（零配置）
- 生产：MySQL/PostgreSQL
- 迁移：Web 可视化迁移工具
