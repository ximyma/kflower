# Kflower 配置指南

## 环境配置

在 `kflower-backend` 目录下创建 `.env` 文件：

```bash
cd D:\kflower\kflower-backend
copy .env.example .env
```

## AI API Key 配置

编辑 `.env` 文件，填入你的 AI API Key：

### 方案一：SiliconFlow（推荐，免费额度）
```env
AI_PROVIDER=siliconflow
SILICONFLOW_API_KEY=你的SiliconFlow密钥
SILICONFLOW_API_BASE=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=Qwen/Qwen3.5-35B-A3B
```

### 方案二：DeepSeek
```env
AI_PROVIDER=deepseek
DEEPSEEK_API_KEY=你的DeepSeek密钥
DEEPSEEK_MODEL=deepseek-chat
```

### 方案三：阿里云通义千问
```env
AI_PROVIDER=qwen
QWEN_API_KEY=你的阿里云密钥
QWEN_MODEL=qwen-max
```

## 获取 API Key

### SiliconFlow
1. 访问 https://siliconflow.cn
2. 注册并登录
3. 进入控制台 → API Key
4. 复制密钥

### DeepSeek
1. 访问 https://platform.deepseek.com
2. 注册并登录
3. API Keys → 创建密钥

### 阿里云通义千问
1. 访问 https://dashscope.console.aliyun.com
2. 开通服务并获取密钥

## 启动服务

### Windows
```bash
cd D:\kflower\kflower-backend
.\启动.bat
```

或手动：
```bash
cd D:\kflower\kflower-backend
.\venv\Scripts\activate
python main.py
```

### 访问地址
- 后端API：http://localhost:8898
- API文档：http://localhost:8898/docs
- 默认账户：admin / admin123

## 前端启动

```bash
cd D:\kflower\kflower-frontend
npm install
npm run dev
```

访问 http://localhost:5173
