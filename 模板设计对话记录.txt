### 动态建表方案

后端发布模板时，根据字段定义动态创建数据表：

```python
# 伪代码
def create_template_data_table(template_id, fields):
    table_name = f"template_data_{template_id}"
    columns = []
    for field in fields:
        sql_type = map_field_type_to_sql(field['type'])  # text->VARCHAR, number->DECIMAL等
        columns.append(f"{field['name']} {sql_type}")
    
    execute(f"CREATE TABLE {table_name} (id INT PRIMARY KEY, {', '.join(columns)}, created_at, updated_at)")
```
