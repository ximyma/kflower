# WorkBuddy 启动配置

## 项目信息

- **项目名称**: Kflower 办公自动化系统
- **项目路径**: D:\kkflower
- **工作区配置**: D:\kkflower\.workbuddy

## 启动时必须加载的文件

| 文件 | 用途 |
|-----|------|
| `SITEMAP.md` | **项目导航地图** - 必须首先加载，包含完整的项目结构、文件位置、功能分类 |
| `memory/MEMORY.md` | 长期记忆 - 项目约定、技术决策、用户偏好 |
| `memory/YYYY-MM-DD.md` | 当日工作日志 |

## 启动流程

1. **读取 SITEMAP.md** - 建立项目全局视图
2. **读取 MEMORY.md** - 获取长期记忆和约定
3. **读取今日记忆** - 获取最新工作进展
4. **检查是否有待处理的任务**

## SITEMAP.md 使用指南

SITEMAP.md 包含：
- 项目目录结构概览
- 后端 API 端点清单
- 数据库模型清单
- 业务服务清单
- 前端视图清单
- 功能关键词速查表
- 问题描述模板

**重要**: 当用户描述问题时，应首先参考 SITEMAP.md 定位相关模块，然后给出导航建议。
