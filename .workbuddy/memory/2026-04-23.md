## 2026-04-23 代码修复

智能表单升级代码被破坏后用户自行修复，但未完全恢复。检查并修复了以下问题：

### 修复内容
1. **SubTableData 字段名不一致**：模型定义用 `parent_table_name` / `parent_field_name`，但 templates.py 提交和查询时误用 `table_name` / `field_name` → 已修正
2. **FormFill.vue onFieldChange 函数缺失**：`onRelationSelect` 后有孤立代码块（公式重算+级联清空），缺少 `onFieldChange` 函数定义 → 提取为独立函数
3. **Lookup API 返回数据格式不匹配**：后端返回 `results` 数组，前端期望 `items` → 前端兼容处理
4. **validate_form_data 未定义变量**：`templates.py` 第1488行引用未定义变量 `err` → 删除该行
5. **Lookup API 路由冲突**：后端 `/{template_id}/lookup` 会被 FastAPI 路径参数匹配，前端调 `/templates/lookup` 时 `template_id` 被设为 `"lookup"` → 改为独立路由 `/lookup`，并新增 `/lookup/{target_template_id}/{data_id}` 端点
