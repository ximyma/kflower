## 矩阵表格功能测试与修复

### 背景
用户测试了昨天完成的矩阵表格功能，发现以下问题：
1. **列维度显示"列2、列3"** - 而不是实际的表头名称（如"2025年部门预算预计数"）
2. **录入界面仍是一维视图** - 没有显示矩阵样式的录入界面
3. **行列动态扩展功能找不到** - 添加/删除行和列的功能不明显

### 完成的修复

#### 1. 后端改进（`import_matrix_service.py`）
- 添加 `_get_cell_value()` 辅助函数：安全获取单元格值
- 添加 `_infer_header_from_context()` 函数：从上下文推断表头（处理合并单元格或空单元格）
- 改进列头提取逻辑：当单元格为空时，尝试从其他行获取表头值

#### 2. 前端 `FormListPage.vue` 修复
- **添加缺失的 ref**：`showMatrixView` （之前使用了但未定义）
- **改进矩阵模板检测**：`isMatrixTemplate` 不再强制要求字段数等于3，而是检测是否包含 `row_dimension`、`col_dimension`、`value` 三个字段
- **更新 `openFormSubmit()`**：如果是矩阵模板，初始化矩阵录入数据
- **更新 `submitDataForm()`**：支持矩阵数据提交（从 `matrixInputData` 提取数据，格式化为 `{__matrix_data: [...]}`）
- **更新填写数据弹窗**：矩阵模板使用 `MatrixInput` 组件，普通模板使用普通表单
