# 2026-04-19 工作日志

## 应用设计器 Bug 修复

修复了"设计"按钮点击后两个报错：

### Bug 1: `templateAPI.list is not a function`
- **根因**：`AppDesigner.vue` 中使用默认导入 `import templateAPI from '@/common/api/index'`，但 `templateAPI` 是具名导出
- **修复**：改为 `import { templateAPI } from '@/common/api/index'`

### Bug 2: `status code 500`（加载应用详情失败）
- **根因 1**：`endpoints.py` 缺少 `from sqlalchemy import select` 导入，调用 `select(AppMenu)` 时 NameError
- **修复**：补充 `from sqlalchemy import select`
- **根因 2**：`service.py` 的 `get_app` 未使用 `selectinload` 预加载关联关系（menus/relations/plugins），异步 SQLAlchemy 下 lazy load 报 MissingGreenlet 错误
- **修复**：改用 `selectinload(Application.menus).selectinload(AppMenu.children)` 等预加载

### 其他修复
- `myApps.ts` 中 `updateMenu`/`deleteMenu`/`deleteRelation`/`updatePlugin`/`deletePlugin` 的 URL 缺少 `/apps` 前缀
  - 修复前：`/menus/${menuId}` → 修复后：`/apps/menus/${menuId}`
  - 关系和插件同理

### 数据库迁移
- 执行 `init_db()` 创建 `applications`/`app_menus`/`form_relations`/`app_plugins` 4 张新表

## 应用发布 500 错误修复

**问题**：发布应用时报 500 错误，`publish_app` 期望 ORM 对象但 `get_app` 返回 dict

**修复**：
- `publish_app` 改为接受 `app_id`，内部查询 ORM 对象，返回 dict
- endpoint 调用改为 `await my_apps_service.publish_app(db, app_id)`
