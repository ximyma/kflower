- `rag.py`：`RAGEmbeddingAdapter` 添加 `set_kb_embedding_config()/embed_text(kb_config=)`；`RAGRetriever.add_document()/search()` 支持传入 `kb_config`
- `knowledge.py`：`_vectorize_document` / `query_knowledge` / `_do_vector_search` / `advanced_search` 均传入 KB embedding 配置；新增 `_build_kb_embedding_config(kb)` 和 `_infer_embedding_type()` 辅助函数

### 移动端设备检测与自动跳转

**问题**：手机上打开程序主页，不会跳转到手机版。

**解决方案**：
1. 在路由守卫（`common/router/index.ts`）中添加设备检测逻辑
2. 手机访问PC端根路径自动跳转到 `/app/login`
3. PC访问手机端路径自动跳转到 `/home`
4. 已登录用户访问根路径根据设备类型跳转到对应首页

**关键代码逻辑**：
```typescript
const isMobile = checkDevice()
const isMobileRoute = toPath.startsWith('/app')
const isPublicRoute = ['/login', '/register', '/app/login', '/app/register'].includes(toPath)

// 手机访问PC端根路径，跳转到手机版登录
if (isMobile && (isRootRoute || (!isMobileRoute && !isPublicRoute))) {
  next('/app/login')
  return
}

// PC访问手机端路径，跳转到PC首页
if (!isMobile && isMobileRoute && !isPublicRoute) {
  next('/home')
  return
}
```

**文件变更**：
- `common/router/index.ts`：添加设备检测路由守卫
- `common/views/Login.vue`：添加 `onMounted` 检测移动设备并跳转
- `common/mobile/views/Login.vue`：重写，使用 Element Plus 替代 Vant
- `common/mobile/views/Register.vue`：新增移动端注册页
- 移动端登录/注册页作为独立公共路由，不嵌套在 AppLayout 下

**BUG修复**：
