## WorkflowDesigner.vue 节点功能完善

按照流程设计.txt（斑斑低代码平台文档）全面完善了流程设计器各节点的配置面板：

### 审批/办理/抄送节点（approval/task/cc）
- 审批类型：人工审批 / 自动通过 / 自动拒绝（Radio Button）
- 审批方式：常规审批 / 逐级审批
- 逐级审批顺序：自下而上 / 自上而下
- 审批人来源：提交人/指定成员角色/部门主管/表单内成员字段/表单内部门字段
- **审批人为空时**：自动通过 / 指定人员 / 转交管理员
- **审批人与提交人相同时**：自己审批 / 转交部门负责人 / 自动跳过
- 操作权限：允许转交、必须填写意见
- **退回配置**：允许退回、退回范围（不限制 / 限制到指定节点）
- 超时设置：超时时间（小时）、超时动作

### 触发节点/数据变化节点（trigger/data_change）
- 触发类型：数据变化 / 定时触发（Cron 表达式）
- **变化类型**：新增 / 修改 / 删除（多选 Checkbox）
- 表单字段权限配置（绑定表单后显示）

### 跨表数据操作节点（add_data/update_data/delete_data）—— 新增3种节点类型
- 目标表单：下拉选择器（替代原来的 ID 输入框）
- 筛选条件（修改/删除）：字段、运算符、值类型（字段值/固定值）
- 数据源表单管理
- **字段映射可视化**：为目标表单每个字段设置赋值方式（不赋值/来自字段/自定义值/公式编辑）

### 条件分支/并行分支节点（condition/parallel）
- **分支优先级**：数字设置，条件分支从左到右按1,2,3...顺序
- 数据源表单管理（带筛选条件）
- **条件组管理（AND/OR）**：
  - 条件组之间 OR 关系，组内条件 AND 关系
  - 条件类型：字段直判 / 公式判断 / 触发类型
  - 支持增删条件组和条件

### 其他改动
- 新增图标：Plus、Delete
- 节点类型列表更新：添加 add_data、update_data、delete_data，删除 parallel_join、data_change
- WorkflowNode.config 类型定义全面扩展
- 新增 JS 函数：addConditionGroup、removeConditionGroup、addCondition、removeCondition、addTargetFilterCondition、removeTargetFilterCondition、handleTargetTemplateChange、getFieldMapping、onFieldMappingTypeChange

## 数据填报节点（data_fill）完整实现

按照需求文档全面完善数据填报节点配置面板，新增独立"填报配置" Tab：

### 填报人配置
- 来源：提交人自己 / 指定成员角色 / 部门主管 / 表单内成员字段 / 表单内部门字段
- 指定成员：用户+角色 el-option-group 多选
- 部门主管：主管选择方式（自下而上/自上而下）+ 主管级别
- 表单字段：绑定成员字段或部门字段下拉

### 办理人为空时
- 处理方式：指定人员办理 / 转交给管理员
- 指定备用人员（可选）

### 操作权限
- 允许转交开关、必须填写意见开关
- 超时时间（小时）、超时动作（通知管理员/自动跳过）

### 填报结束条件（核心功能）
- enable_finish_condition 开关控制
- finish_data_sources：额外数据源表单（template_id + alias）
- finish_condition_groups：条件组（OR关系），条件组内 AND 关系
  - 条件类型：字段判断（字段+运算符+值） / 公式判断
  - 字段选择：本条数据 + 各数据源表单字段

### 新增函数
addFinishDataSource, removeFinishDataSource, addFinishConditionGroup, removeFinishConditionGroup, addFinishCondition, removeFinishCondition

### 类型扩展
WorkflowNode.config 新增：enable_finish_condition, finish_data_sources, finish_condition_groups
