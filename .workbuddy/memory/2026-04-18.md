### 使用说明

#### 启动服务
```bash
# 后端
cd e:\kkflower\kflower-backend
.\venv\Scripts\python.exe main.py

# 前端
cd e:\kkflower\kflower-frontend
npm run dev
```

#### 使用流程
1. 登录系统 (admin/admin123)
2. 点击左侧菜单"我的应用"
3. 点击"新建应用"创建应用（如"客户关系管理系统"）
4. 点击"设计"按钮进入应用设计器
5. 从左侧拖拽已发布的模板到菜单
6. 配置菜单属性（名称、图标、排序）
7. 保存并发布应用
8. 点击"进入"使用应用
