## WorkflowDesigner.vue 模板绑定错误修复

用户点击“设计”按钮时报错，Vue模板转换错误：

```
[plugin:vite:vue] Transform failed with 2 errors:
E:/kkflower/kflower-frontend/src/pc/views/WorkflowDesigner.vue:1039:99: ERROR: Invalid assignment target
E:/kkflower/kflower-frontend/src/pc/views/WorkflowDesigner.vue:1049:99: ERROR: Invalid assignment target
```

**问题原因**：
- 模板中使用 `v-model="nodeConfig.plugins?.before"` 和 `v-model="nodeConfig.plugins?.after"`
- Vue 3 的 `v-model` 不能绑定到可选链操作符（`?.`）上，因为 `?.` 是只读访问器，不能用于赋值

**修复方案**：
1. 移除模板中的可选链操作符：
   - `v-model="nodeConfig.plugins?.before"` → `v-model="nodeConfig.plugins.before"`
   - `v-model="nodeConfig.plugins?.after"` → `v-model="nodeConfig.plugins.after"`
   
2. 在 `nodeConfig` 计算属性中确保 `plugins` 对象存在：
   ```typescript
   const nodeConfig = computed(() => {
     if (!selectedNodeData.value) return {}
     if (!selectedNodeData.value.config) {
       selectedNodeData.value.config = {}
     }
     // 确保 plugins 对象存在
     if (!selectedNodeData.value.config.plugins) {
       selectedNodeData.value.config.plugins = { before: '', after: '' }
     }
     return selectedNodeData.value.config
   })
   ```

**验证**：

### 一、修复Vue模板绑定错误
1. **问题定位**：点击“设计”按钮时报错 `[plugin:vite:vue] Transform failed with 2 errors: ... ERROR: Invalid assignment target`
2. **根本原因**：`v-model` 不能绑定到可选链操作符 `?.`，因为 `?.` 是只读访问器，不能用于赋值操作
3. **修复方案**：
   - 移除 `v-model="nodeConfig.plugins?.before"` 中的可选链，改为 `v-model="nodeConfig.plugins.before"`
   - 在 `nodeConfig` 计算属性中确保 `plugins` 对象存在：`selectedNodeData.value.config.plugins = { before: '', after: '' }`
4. **验证结果**：用户确认“现在可以打开流程审批的设计按钮了”
