### 4. 修复 MatrixInput 组件初始化错误
- **错误**: `Cannot read properties of undefined (reading '0')` at MatrixInput.vue:55
- **原因**: Vue 模板同步渲染时，`cellData` 仍为空数组，直接访问 `cellData[rowIdx][colIdx]` 报错
- **修复**:
  1. 添加 `onMounted` 钩子 → 组件挂载时立即调用 `initData()`
  2. 添加 `immediate: true` 到 watch → props 就绪时立即初始化
  3. 模板中添加防御性检查 → `v-if="cellData[rowIdx]"` 防止访问空数组元素
- **教训**: Vue 模板是同步渲染的，watch 回调是异步的。初始化逻辑不能只放在 watch 中。

### 2026-05-04 下午 - 修复 MatrixInput 组件渲染错误

#### 问题
用户点击"新增矩阵数据"按钮时，页面卡死，控制台报错：
```
MatrixInput.vue:52 TypeError: Cannot read properties of undefined (reading '0')
```

#### 原因分析
1. **主要错误**: `matrixData` 在 `onMounted` 时才初始化，但模板渲染时可能还未准备好
2. **次要错误**: `el-input-number` 期望 `Number | Null`，但收到了空字符串 `''`

#### 修复内容

**1. MatrixInput.vue 修复**:
- 将 `onMounted` 初始化改为 `watch` 的 `immediate: true`（组件创建时立即初始化）
- 默认值从空字符串 `''` 改为 `null`（兼容 el-input-number）
- 数据填充时将值转换为数字或 null
- `getColumnTotal` 和 `toOneDimFormat` 函数增加 null 值处理

**2. FormListPage.vue 修复**:
- `initMatrixInputData` 函数：默认值从 `''` 改为 `null`
- `saveMatrixData` 函数：增加 `null` 值和 `isNaN` 检查

**3. 第二次修复 - Maximum recursive updates exceeded 错误**
用户输入数字后，点击另一个输入框就消失，控制台报错：`Maximum recursive updates exceeded`

#### 问题分析
1. `watch(matrixData, ...)` 在数据变化时触发 `emit('update:modelValue')`
2. 父组件更新 `matrixInputData`，又触发新的 watch
3. 形成无限递归循环

#### 解决方案
完全重构 MatrixInput 组件，移除 v-model 依赖，改用事件驱动方式：
1. 使用 `cellData` 内部管理矩阵数据
2. 通过 `getData()` 方法获取一维格式数据
3. 通过 `setData()` 方法设置初始数据
4. 父组件通过 `ref` 调用这些方法

#### 修改内容

**MatrixInput.vue 完全重写**:
- 移除 `modelValue` prop 和 `v-model` 支持
- 使用 `cellData` 内部管理二维数组
- 添加 `getData()` 方法：返回一维格式数据
- 添加 `setData()` 方法：设置初始数据
- 添加 `defineExpose` 暴露方法给父组件

**FormListPage.vue 大幅修改**:
- 添加 `matrixInputRef` 和 `matrixInputRef2` 两个 ref
- 修改 `saveFormData`：使用 `matrixInputRef.value?.getData()`
- 修改 `submitDataForm`：使用 `matrixInputRef2.value?.getData()`
- 修改 `editMatrixData`：使用 `matrixInputRef.value?.setData()`
- 修改 `createNewMatrix`：使用 `matrixInputRef.value?.setData()`
- 修改 `openFormSubmit`：使用 `matrixInputRef2.value?.setData()`
- 删除孤立的 `showMatrixEditDialog` 弹窗和 `saveMatrixData` 函数
- 删除不再使用的 `initMatrixInputData`、`handleMatrixInputUpdate` 函数和 `matrixInputData` 变量
- 添加 `nextTick` 导入

#### 经验教训
- Vue 3 中 v-model 在深层响应式数据上可能导致无限递归
- 事件驱动方式（ref + defineExpose）比 v-model 更可控
- 父子组件数据同步应使用显式方法调用，而非隐式双向绑定
