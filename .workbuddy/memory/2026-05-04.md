## 修复矩阵表格步骤3列维度显示问题

### 问题现象
用户测试发现：预览时行列维度都有正确的表头显示，但第3步骤（调整字段）时列维度变成了"列1、列2"，没有显示实际的表头名称。

### 根本原因
后端 `_infer_header_from_context` 函数有缺陷：
1. **只检查直接左边单元格**，如果合并跨度多列会失败
2. **错误地为水平合并添加序号**（如"Q1(3)"），导致显示不正确

### 完成的修复

#### 1. 后端修复
**文件**：`kflower-backend/app/services/import_matrix_service.py`

改进 `_infer_header_from_context` 函数：
- **迭代搜索左边单元格**（而不仅仅检查直接左边），正确处理多列合并
- **搜索上方和下方行**（处理垂直合并）
- **返回找到的值**（不再添加序号后缀）

#### 2. 前端修复
**文件**：`kflower-frontend/src/pc/views/Templates.vue`

改进 `applyMatrixHeader` 函数：
- 添加更详细的日志输出（方便调试）
- 改进字段标签智能推断逻辑
- 从原始数据重新提取列维度选项（如果后端返回不正确）

### 技术细节

**后端改进**：
```python
# 旧逻辑：只检查直接左边单元格，错误添加序号
if col_idx > 0:
    left_cell = all_rows[header_row_idx][col_idx - 1]
    if left_cell and _get_cell_value(left_cell):
        base_val = _get_cell_value(left_cell)
        return f"{base_val}({col_idx + 1})"  # 错误：添加序号

# 新逻辑：迭代搜索左边所有单元格，返回找到的值
for j in range(col_idx - 1, -1, -1):  # 从当前列向左搜索
    if j < len(all_rows[header_row_idx]):
        val = _get_cell_value(all_rows[header_row_idx][j])
        if val:
            return val  # 正确：直接返回值
```

**前端改进**：
```typescript
// 添加日志输出
console.log('applyMatrixHeader: importFields =', importFields.value)

// 如果后端返回的 options 不正确，从原始数据重新提取
if (!colDim.options || colDim.options.length === 0) {
  const allRows = importData.all_rows || []
  const colIdx = matrixColHeaderCol.value
  const rowHeaderIdx = matrixRowHeaderRow.value
  
  const optionsSet = new Set<string>()
  for (let i = rowHeaderIdx + 1; i < allRows.length; i++) {
    if (allRows[i] && allRows[i][colIdx]) {
      const val = String(allRows[i][colIdx]).trim()
      if (val && !val.startsWith('列')) {  // 排除默认的"列1"、"列2"
        optionsSet.add(val)
      }
    }
  }
  
  if (optionsSet.size > 0) {
    colDim.options = Array.from(optionsSet)
  }
}
```
