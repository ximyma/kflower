## 🔧 安装前检查

### 系统要求

- [ ] CPU: 2 核+
- [ ] 内存: 4GB+
- [ ] 磁盘: 50GB+
- [ ] 系统: Ubuntu 20.04+ / CentOS 7+ / Windows Server 2019+

### 依赖检查

```bash
# 检查 Python 版本
python3 --version  # 需要 3.11+

# 检查 Node.js 版本
node --version  # 需要 18.x+

# 检查 NPM 版本
npm --version  # 需要 9.x+
```

## 📥 安装步骤

### 方式一：手动部署

```bash
# 1. 解压发布包
tar -xzf KFlower-v1.0.0.tar.gz
cd KFlower-v1.0.0

# 2. 安装后端
cd kflower-backend
pip install -r requirements.txt
python main.py  # 启动服务

# 3. 安装前端
cd ../kflower-frontend
npm install
npm run build

# 4. 配置 Nginx（参考部署文档）
```

### 方式二：Docker 部署

```bash
# 一键启动
docker-compose up -d
```

## 🔐 初始配置

### 1. 修改配置

编辑 `kflower-backend/config.yaml`:

```yaml
# JWT 密钥（必须修改）
jwt:
  secret_key: "你的32位以上随机密钥"

# AI API Key
ai:
  api_key: "你的OpenAI API Key"
```

### 2. 创建管理员

```bash
cd kflower-backend
python scripts/create_admin.py
```

### 3. 首次登录

1. 访问 `http://your-server/`
2. 使用管理员账号登录
3. 建议立即修改密码

## 📋 打包命令

```bash
#!/bin/bash
VERSION="1.0.0"
DATE=$(date +%Y%m%d)

# 创建发布目录
rm -rf KFlower-v${VERSION}
mkdir -p KFlower-v${VERSION}

# 复制文件
cp -r kflower-backend KFlower-v${VERSION}/
cp -r kflower-frontend KFlower-v${VERSION}/
cp -r docs KFlower-v${VERSION}/
cp -r scripts KFlower-v${VERSION}/
cp -r docker KFlower-v${VERSION}/
cp README.md KFlower-v${VERSION}/

# 打包
tar -czvf KFlower-v${VERSION}-${DATE}.tar.gz KFlower-v${VERSION}/
zip -r KFlower-v${VERSION}-${DATE}.zip KFlower-v${VERSION}/

echo "打包完成: KFlower-v${VERSION}-${DATE}"
```
