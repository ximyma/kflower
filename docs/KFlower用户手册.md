## 1. 产品简介

### 1.1 什么是 KFlower

KFlower 是一款基于 AI 技术的智能低代码平台，帮助企业快速构建管理应用程序。通过可视化表单设计、智能工作流、AI 智能体编排等能力，大幅降低开发成本。

### 1.2 核心能力

| 模块 | 功能描述 |
|------|----------|
| **智能表单** | 可视化表单设计，支持公式计算、级联联动、子表汇总 |
| **工作流引擎** | 流程审批、会签、或签、条件分支、自动触发 |
| **AI 智能体** | 智能客服、数据分析、代码助手等多场景 AI 应用 |
| **知识库** | 文档管理、RAG 检索、向量数据库集成 |
| **应用编排** | 拖拽式应用构建、多端自适应（PC/移动） |

### 1.3 系统架构

```
┌─────────────────────────────────────────────────────────────┐
│                      前端 (Vue 3 + Element Plus)            │
│   PC管理后台  │  移动端H5  │  AI智能体对话                    │
├─────────────────────────────────────────────────────────────┤
│                      后端 (FastAPI + SQLAlchemy)            │
│   API网关  │  业务服务  │  AI服务  │  工作流引擎              │
├─────────────────────────────────────────────────────────────┤
│                      数据层 (SQLite / PostgreSQL)           │
│   表单数据  │  应用数据  │  AI记录  │  工作流数据             │
├─────────────────────────────────────────────────────────────┤
│                      AI 能力层                               │
│   模型管理  │  能力注册  │  智能体引擎  │  工具执行器          │
└─────────────────────────────────────────────────────────────┘
```

## 2. 快速开始

### 2.1 登录系统

1. 访问系统地址，如 `http://localhost:5173`
2. 输入用户名和密码登录
3. 首次登录建议修改默认密码

### 2.2 界面布局

```
┌──────────────────────────────────────────────────────────────┐
│  LOGO        工作台    表单设计    我的应用    AI助手    设置  │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│   ┌─────────┐                                               │
│   │ 快捷入口 │   欢迎使用 KFlower 智能低代码平台              │
```

### 2.3 创建第一个应用（5步完成）

1. **新建模板** → 进入「表单设计」创建数据表单
2. **配置字段** → 拖拽添加字段，设置验证规则
3. **发布模板** → 保存并发布模板
4. **创建应用** → 进入「我的应用」创建应用
5. **添加菜单** → 将模板添加到应用菜单

## 4. 表单设计器

### 4.1 字段类型

| 类型 | 用途 | 示例 |
|------|------|------|
| 单行文本 | 简短文字 | 姓名、编号 |
| 多行文本 | 长文本内容 | 备注、描述 |
| 数字 | 数值输入 | 年龄、价格 |
| 日期时间 | 日期选择 | 生日、预约时间 |
| 单选/多选 | 选项选择 | 性别、爱好 |
| 下拉框 | 下拉选择 | 部门、状态 |
| 图片上传 | 图片文件 | 头像、证件照 |
| 文件上传 | 任意文件 | 附件、合同 |
| 开关 | 是/否切换 | 是否启用 |
| 分隔符 | 视觉分隔 | 分组标题 |
| 公式 | 自动计算 | 金额=单价×数量 |

### 4.2 字段属性配置

点击字段可配置以下属性：

```
┌─────────────────────────────────────────────┐
│  字段属性                                    │
├─────────────────────────────────────────────┤
│  标题: [客户名称          ]                  │
│  字段名: [customer_name   ]                  │
│  占位提示: [请输入客户名称  ]                │
│  必填: [✓]                                  │
│  默认值: [                  ]               │
│  验证: [最大长度 100 字符  ▼]               │
│                                             │
│  ───────── 高级选项 ─────────               │
│  可见条件: [条件1 ▼] [+添加条件]            │
│  公式计算: [单价 × 数量       ]              │
│  智能联想: [○]                              │
└─────────────────────────────────────────────┘
```

### 4.3 公式引擎

支持 20+ 内置函数：

| 函数类别 | 函数示例 | 说明 |
|----------|----------|------|
| 数学 | SUM, AVG, MAX, MIN, COUNT | 聚合计算 |
| 逻辑 | IF, AND, OR, NOT | 条件判断 |
| 文本 | CONCAT, SUBSTRING, TRIM | 文本处理 |
| 日期 | NOW, DATE, DATEDIFF | 日期操作 |
| 查找 | VLOOKUP, LOOKUP | 数据关联 |

**示例**：
- 金额自动计算：`单价 * 数量`
- 状态判定：`IF(金额 > 10000, "大额", "普通")`
- 汇总子表：`SUM(明细表.subtotal)`

### 4.4 智能表单特性

#### 4.4.1 级联联动
当下拉选项需要联动时使用：
- 省份 → 城市 → 区县
- 部门 → 职位

#### 4.4.2 子表/明细表
支持在表单中嵌入表格：
- 订单明细
- 费用明细
- 考勤记录

#### 4.4.3 关联填充
选择一个值后自动填充其他字段：
- 选择客户 → 自动填充联系人、电话

## 7. 工作流引擎

### 7.1 工作流设计器

可视化流程设计，支持多种节点类型：

| 节点类型 | 图标 | 说明 |
|----------|------|------|
| 开始 | 🟢 | 流程起点 |
| 结束 | 🔴 | 流程终点 |
| 审批节点 | 👤 | 单人/多级审批 |
| 填写节点 | 📝 | 表单填写 |
| 条件节点 | ◇ | 条件分支 |
| 处理节点 | ⚙️ | 自动处理 |
| 通知节点 | 📧 | 消息通知 |
| 子流程 | 📦 | 调用子流程 |

### 7.2 审批人配置

支持多种审批人来源：

| 来源 | 说明 |
|------|------|
| 指定人员 | 固定人员审批 |
| 发起人自选 | 发起人选择审批人 |
| 部门主管 | 按部门层级向上 |
| 角色 | 按系统角色分配 |
| 表单字段 | 从表单字段取值 |

### 7.3 条件分支

支持复杂条件判断：

```
IF(金额 > 50000, "总监审批", 
  IF(金额 > 10000, "经理审批", 
    "主管审批"))
```

### 7.4 表单数据联动

工作流节点可以：
- 读取表单数据作为变量
- 更新表单字段值
- 基于表单数据决定流程走向

## 12. 常见问题

### Q1: 如何导出应用数据？

进入应用 → 点击右上角「...」→「导出数据」

### Q2: 表单提交失败怎么办？

1. 检查必填字段是否填写
2. 检查字段格式是否正确
3. 查看网络连接状态
4. 查看浏览器控制台错误信息

### Q3: 如何重置密码？

联系系统管理员在用户管理中重置。

### Q4: 如何备份数据？

系统数据存储在数据库文件中，定期备份 SQLite 文件或数据库目录。

### Q5: 支持多语言吗？

当前版本支持中文界面。
